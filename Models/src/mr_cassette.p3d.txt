# Здесь — текстовая инструкция-заглушка, как создать .p3d из .obj (согласно 07_MODELS.md п. 1-4)

# Источник: Models/src/mr_cassette.obj (100 × 63.8 × 12 мм)
# Материалы: plastic, metal, label (согласно 07_MODELS.md п. 4)
# LOD-схема: Resolution 0.000, View Geometry, Geometry, Memory (согласно 07_MODELS.md п. 3)
# Memory LOD: ce_center, MR_MemCard, MR_Media (согласно 07_MODELS.md п. 3)

# 1. Import Wavefront (.obj) -> mr_cassette.obj (масштаб 1.0)
# 2. Bounding Center (согласно 07_MODELS.md п. 2)

# 4. Save как .p3d (согласно 07_MODELS.md п. 1)
